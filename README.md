# Пасека — Windows releases

Здесь публикуются только Windows-установщик, подписанный манифест и служебные контрольные суммы. Исходники, ключи и пользовательские данные здесь не хранятся.

Подпись манифеста подтверждает источник и целостность обновления, но не является цифровой подписью издателя Windows (Authenticode). Системное предупреждение SmartScreen возможно.
